# ナナイロ作業報告入力ツール

ナナイロ様へ毎月提出する作業報告書を、日別入力・月間工数の確認・Excel/PDF出力まで一画面で作成するWindowsデスクトップアプリです。

## 主な機能

- 対象月の日付、曜日、土日祝日を自動生成
- 通常勤務、公休日、有給休暇の区分に応じた入力と月間集計
- 当日までの実績工数、月末見込み、精算幅、有給取得目安を表示
- 複数日への勤務区分・作業内容・公休日・標準時間の一括設定
- エラー／警告チェックと該当日への移動
- UTF-8 JSON形式の `.nwr` 下書き保存、自動復旧、最近使ったファイル
- マクロなし `.xlsx` の出力・再読込
- デスクトップ版Microsoft Excelを利用した1ページPDF出力
- 内閣府の祝日CSVを同梱し、手動・バックグラウンド更新に対応

## 必要環境

- Windows 11 x64
- PDF出力時のみデスクトップ版Microsoft Excelが必要
- 配布版は自己完結型のため、利用者による.NETのインストールは不要

## 使用方法

### 1. 起動と基本情報の入力

1. 配布された `NanairoWorkReportTool.exe` を起動します。
2. `入力月`へ `yyyy/MM` 形式（例：`2026/07`）で対象月を入力し、`月を生成`を押します。
3. `入力者名`、`会社名`、`提出先`を入力します。
4. `保存先`でExcelとPDFの出力先フォルダーを指定します。

対象月を生成すると、平日は通常勤務、土日祝日は未設定で初期化されます。通常勤務の標準時間は開始`09:00`、終了`17:30`、休憩`1.00`時間です。月の変更時に未保存の入力がある場合は、保存確認が表示されます。

### 2. 日別の勤務内容を入力

日別入力一覧の`勤務区分`を選び、区分に応じて必要な内容を入力します。

| 勤務区分 | 入力内容 | 工数上の扱い |
| --- | --- | --- |
| 通常勤務 | 作業内容、開始、終了、休憩を入力 | 入力時刻から工数を計算 |
| 有給休暇 | 作業内容や勤務時刻の入力は不要 | 基準工数には残し、実績は0時間 |
| 公休日 | 公休日名を入力 | 平日稼働日数と基準工数から除外 |
| 未設定 | 入力不要 | 実績は0時間 |

開始・終了は`HH:mm`形式、休憩は時間単位で入力します。作業内容は複数行入力できます。

### 3. 複数日をまとめて編集

日別入力一覧で`Ctrl`または`Shift`を押しながら行を選択すると、次の一括操作ができます。

- 勤務区分を一括設定
- 直近20件の候補から作業内容を一括設定
- 公休日名を指定して公休日を一括設定
- 標準時間へ復元
- 勤務時間をクリア
- 前日の作業内容をコピー

### 4. 月間集計を確認

画面上部に、平日稼働日数、公休日、有給休暇、基準工数、上下限、当日までの実績、月末見込み、下限までの余裕、有給取得目安、精算幅判定が表示されます。

- `当日まで`は過去日と当日の実績工数です。
- `月末見込み`は未来日の標準勤務時間を含みます。
- 精算幅と有給取得目安は月末見込みを基準に計算します。

### 5. 入力内容をチェック

`チェック`を押すと、画面下部にエラーと警告が表示されます。

- 現在月の過去日・当日の必須項目不足はエラーです。
- 未来日の入力不足は警告です。
- 開始・終了の前後関係など、入力値の矛盾は未来日でもエラーです。
- チェック結果をダブルクリックすると、該当日の行へ移動します。

エラーがある場合はExcel/PDFを出力できません。警告のみの場合は、確認後に見込み帳票として出力できます。

### 6. 下書きの保存と再読込

`保存 (.nwr)`を押すと、入力途中の内容を専用の`.nwr`ファイルへ保存します。下書き保存はエラーが残っていても可能です。

次の方法で保存データを開けます。

- `ファイルを開く`から`.nwr`または本ツールが出力した`.xlsx`を選択
- ファイルを画面へドラッグ＆ドロップ
- `最近のファイルを開く`から直近10件を選択

編集中の内容は自動復旧データにも保存されます。前回の作業が正常に保存されず終了した場合は、次回起動時に復旧データを開きます。

### 7. Excel・PDFを出力

1. 保存先フォルダーを確認します。
2. `Excel出力`または`PDF出力`を押します。
3. 警告が表示された場合は内容を確認し、出力を続けるか選択します。
4. 完了画面からExcel、PDF、保存先フォルダーを開けます。

Excelはマクロを含まない`.xlsx`形式で出力されます。PDF出力では同じExcelを更新してから、デスクトップ版Microsoft Excelを非表示で起動して1ページのPDFへ変換します。

### 8. 祝日情報を更新

祝日情報は内閣府の公式CSVを基にしています。起動時にバックグラウンドで確認され、`祝日情報更新`から手動更新もできます。更新後の情報は、対象月を再生成すると反映されます。

## 注意事項

- 既存の`.xlsm`ファイルは読み込めません。読み込めるExcelは本ツールが生成した`.xlsx`のみです。
- PDF出力にはデスクトップ版Microsoft Excelが必要です。Excelがない環境でも`.nwr`の保存と`.xlsx`の生成は利用できます。
- 出力先のExcelやPDFを開いたまま上書きすると失敗する場合があります。対象ファイルを閉じてから再実行してください。
- クラウド同期、データベース共有、複数ユーザーでの同時編集、自動アプリ更新には対応していません。

## 開発

```powershell
dotnet test NanairoWorkReportTool.slnx -c Release
dotnet publish src\NanairoWorkReportTool\NanairoWorkReportTool.csproj -c Release -r win-x64 --self-contained true -o publish\win-x64
```

技術構成は .NET 10 / WPF / MVVM / Open XML です。帳票テンプレートは実帳票の外観・印刷設定を引き継いだマクロなし形式を同梱しています。
